# AVCam tutorial app

This repository contains the iOS project of the AVCam tutorial. In the tutorial, you rebuild Apple's sample app [AVCam: Building a camera app](https://developer.apple.com/documentation/avfoundation/avcam-building-a-camera-app) step by step.

## Branches

Each branch contains the finished code of one chapter. The finished code of one chapter is the start code of the next chapter.

| Branch | Contents |
|---|---|
| `start` | The project as Xcode 27.1 creates it from the iOS App template. |
| `chapter-01` ... `chapter-13` | The finished code of chapters 1 to 13. |
| `main` | The last finished chapter. |

To start a chapter, check out the branch of the chapter before it. For example, check out `start` for chapter 1, or `chapter-04` for chapter 5.

## Tutorial site

The tutorial pages are in the sibling folder `AVCamTutorialSite`.

## Requirements

- Xcode 27.1
- iOS 26.0 or later
